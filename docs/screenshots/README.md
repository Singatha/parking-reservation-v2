# Screenshot guidelines

Use a clean local dataset and avoid capturing real names, email addresses,
credentials, browser extensions, or operating-system notifications.

Recommended README images:

- `parking.png` — available parking spaces in the light theme
- `reservation.png` — the new-reservation form and booking summary
- `invoices-dark.png` — the invoice table in the dark theme
- `manage-spaces.png` — administrator parking-space management

Capture images at a consistent desktop viewport, crop unnecessary browser chrome,
and optimize the files before committing them. Once added, embed them in the main
README with relative paths such as:

```md
![Available parking spaces](docs/screenshots/parking.png)
```
